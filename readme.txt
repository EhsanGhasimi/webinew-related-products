Article-based WooCommerce recommendations calculated on save, with manual overrides and an accessible RTL product slider. By Ehsan Ghasimi and Webinew.

== Description ==
Webinew Related Products matches article keywords to product names, categories, tags and short descriptions when an article is saved. A shortcode displays the stored recommendations without scanning the catalog during page views.

Developed by احسان قسیمی | شرکت وبینیو. Visit https://webinew.com/ for WordPress development, website design and SEO services.

Includes manual product IDs, Persian text normalization, live WooCommerce prices, product images, purchase links and five-second autoplay with pause/play controls.

No AI API, telemetry, external recommendation service or public promotional footer. Requires active WooCommerce. Save-time scanning may be slow for very large catalogs; see README.md for limitations.

== Installation ==
1. Upload and activate the plugin with WooCommerce active.
2. Save an article, then reload the editor to inspect its recommendations.
3. Add [webinew_related_products] to a sidebar Shortcode widget or Elementor article template.
4. Use manual mode in the article meta box to change IDs and order.

If upgrading from the initial project-specific plugin, deactivate that version first. Saved selections and the old shortcode remain supported.
